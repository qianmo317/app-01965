# 俄罗斯方块 AI 游戏

一款基于 HTML5 的俄罗斯方块游戏，具有 AI 自动游玩模式和强化学习功能。

## 1. How to Run

### 使用 Docker（推荐）

1. **使用 Docker Compose 构建并运行：**
   ```bash
   docker-compose up --build -d
   ```

2. **访问游戏：**
   打开浏览器访问：`http://localhost:8081`

3. **停止容器：**
   ```bash
   docker-compose down
   ```

### 本地开发

1. **进入前端目录：**
   ```bash
   cd frontend-user
   ```

2. **安装依赖（用于测试）：**
   ```bash
   npm install
   ```

3. **运行测试：**
   ```bash
   npm test
   ```

4. **本地启动服务：**
   可以使用任何静态文件服务器。例如，使用 Python：
   ```bash
   python -m http.server 8080
   ```
   或使用 Node.js http-server：
   ```bash
   npx http-server -p 8080
   ```

5. **访问游戏：**
   打开浏览器访问：`http://localhost:8080`

## 2. Services

| 服务 | 描述 | 端口 |
|------|------|------|
| frontend-user | 通过 Nginx 提供的带 AI 功能的 HTML5 俄罗斯方块游戏 | 8081 |

### 服务详情

**frontend-user**
- 提供俄罗斯方块游戏的静态 Web 应用
- 使用原生 JavaScript 构建（无框架依赖）
- 在 Docker 中使用 Nginx 作为 Web 服务器
- 支持 ARM 和 X86 架构
- 包含容器监控的健康检查

## 3. 测试账号

这是一个完全在浏览器中运行的客户端游戏应用。**无需用户账户或身份验证**即可游玩。

所有游戏数据（包括 AI 学习统计）都存储在浏览器的本地存储中。

## 4. 题目内容

开发一个基于HTML的俄罗斯方块游戏应用，该应用需包含以下核心功能和技术要求：

1. **基础游戏功能**：实现完整的俄罗斯方块游戏机制，包括方块随机生成、移动、旋转、消除行、计分系统和游戏结束判定。

2. **AI自动玩模式**：开发具备自动学习能力的AI系统，能够独立操作游戏。AI应实现以下功能：
   - 自主决策方块的放置位置和旋转角度
   - 具备强化学习能力，通过不断游戏积累经验并优化策略
   - 记录和分析游戏数据，持续提升游戏表现
   - 最终达到超越人类顶级玩家的水平，实现接近理论最优解的游戏策略

3. **用户界面要求**：设计直观友好的游戏界面，包含游戏区域、分数显示、下一个方块预览、AI控制开关、游戏速度调节等功能模块。

4. **技术实现要求**：使用HTML5 Canvas或SVG进行游戏渲染，采用JavaScript实现游戏逻辑和AI算法，确保代码结构清晰、性能优化良好，游戏运行流畅无卡顿。

5. **学习系统要求**：AI需实现有效的状态评估函数、探索与利用平衡机制、以及性能记录和策略优化系统，能够在无监督环境下自主学习和进步。

## 项目描述

本项目实现了一个完整的俄罗斯方块游戏，包含以下功能：

### 核心游戏功能
- **标准俄罗斯方块机制**：支持全部 7 种方块形状（I、O、T、S、Z、J、L），具有正确的旋转和踢墙系统
- **键盘控制**：方向键移动，空格键硬降，Z 键逆时针旋转
- **计分系统**：根据消除行数计分（1/2/3/4 行分别得 100/300/500/800 分）
- **下一个方块预览**：显示即将出现的方块
- **幽灵方块**：显示方块落地位置的预览

### AI 功能
- **AI 自动游玩模式**：可切换 AI 自动玩游戏
- **状态评估**：AI 使用聚合高度、完整行数、空洞数和凹凸度等指标评估棋盘状态
- **强化学习**：使用 ε-贪婪策略平衡探索与利用
- **学习数据持久化**：AI 学习数据保存到浏览器本地存储
- **统计追踪**：追踪游戏次数、平均分数、最高分数和消除行数

### 技术栈
- HTML5 + CSS3 + JavaScript (ES6+)
- HTML5 Canvas API 用于渲染
- Local Storage API 用于 AI 数据持久化
- Docker + Nginx 用于部署
- Jest + fast-check 用于测试（单元测试和属性测试）

## 游戏控制

| 按键 | 操作 |
|------|------|
| ← (左方向键) | 向左移动方块 |
| → (右方向键) | 向右移动方块 |
| ↓ (下方向键) | 软降（加速下落） |
| ↑ (上方向键) | 顺时针旋转 |
| Z | 逆时针旋转 |
| 空格 | 硬降（瞬间落下） |
